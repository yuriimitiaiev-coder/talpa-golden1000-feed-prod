# Golden980 — перевірка фактичної закупівлі (01.11.2026)

Рішення власника: повний перегляд усіх 980 чинних SKU, виключити 35 Grand Instrument, вибрати найкращий асортимент лише серед SIGMA і ZaInstrumentom. Поточний live Prom і main GitHub НЕ змінювати до завершення економічного аудиту.

Створено приватний робочий Excel `TALPA_Golden980_PROCUREMENT_VERIFICATION_998_2026-11-01.xlsx` (не додавати в публічний репозиторій): **998 унікальних SKU** для звірки закупівельних цін = 945 чинних SIGMA/Za + 53 потенційні альтернативи. SIGMA 653 (632+21), ZaInstrumentom 345 (313+32). Grand 35 виключено з реєстру.

У формі є поле **ФАКТ закупівлі / шт**, джерело та дата, параметри фінансового сценарію, розрахункова маржа ProSale і власного сайту, ціль 80 грн для одиничного замовлення. Не вимагати ручного переписування 998 позицій: після отримання вихідного CSV/XLSX з B2B SIGMA і партнерських прайсів ZaInstrumentom програмно зіставити SKU та ціну. Статус доступної закупівельної ціни зараз **0/998**: історичні 27% / 25% / 30% не приймати як фактичні ціни, а XML містить RRP.

Наявні підтвердження із підключеної пошти:
- SIGMA: запрошення в персональний B2B-кабінет (серпень 2026), але не експорт закупівельних цін.
- ZaInstrumentom: комунікації з постачальником і старі бренд-прайси; не поточний підтверджений закупівельний CSV усіх 345 SKU.

Ключове: економічний PASS можливий після отримання дійсних цін **для TALPA як ТОВ без ПДВ**. Окремо перевірити статус комісій ProSale/еквайрингу. Дешеві SKU можуть бути вигідні у складі замовлення, їх не вилучати лише за сценарієм одиничної покупки.
