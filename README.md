# TALPA Golden1000 — керований пул до 1000 SKU

Цей репозиторій публікує контрольований XML/YML-фід TALPA для Prom.ua.

**Golden1000 — це максимальна місткість, а не обов'язково 1000 живих товарів.**
Поточна стартова конфігурація: **950 ACTIVE + 50 вільних місць**.

## Один керуючий пул

Каталог логічно керується одним пулом, фізично розбитим на файли `pool/catalog_pool_*.csv` для надійного редагування через GitHub.

Поля:
- `sku` — артикул TALPA;
- `supplier` — `SIGMA`, `ZAINSTRUMENTOM`, `TEKNOSEL`, `GRANDINSTRUMENT` або `GPL`;
- `status` — `ACTIVE` або `RESERVE`;
- `prom_offer_id` — стабільний ID позиції Prom; для вже існуючих 950 він зафіксований із фінального експорту;
- `prom_group_id` — ідентифікатор існуючої групи TALPA;
- `fallback_price` — остання контрольна ціна для безпечного fallback, якщо SKU тимчасово зник із фіда постачальника.

У фід потрапляють тільки рядки `ACTIVE`. `RESERVE` не публікується.
Сума налаштованих рядків і кількість ACTIVE не можуть перевищувати 1000.

## Як змінювати кількість живих товарів

- Додати товар: додати рядок у один із `pool/catalog_pool_*.csv` зі статусом `ACTIVE` або перевести готовий `RESERVE` у `ACTIVE`.
- Вивести товар із фіда: `ACTIVE -> RESERVE`.
- Для фізичного видалення/приховування товару в Prom виконується окрема контрольована дія в Prom — відсутність SKU у фіді сама по собі не повинна видаляти картку.

Після зміни `pool/catalog_pool_*.csv` GitHub Actions запускається одразу. Додатково збірка працює кожні 4 години.

## Що оновлюється автоматично

Для чинних карток TALPA скрипт зберігає їхню структуру та ідентичність і бере від призначеного постачальника тільки комерційні поля:
- ціна;
- наявність;
- кількість.

SIGMA не передає окремий залишок, тому для SIGMA використовується `1` при `available=true` і `0` при `available=false`.
ZaInstrumentom передає `quantity_in_stock`, і воно використовується напряму.
Для чотирьох погоджених GPL-карток використовується контрольований статичний snapshot `sources/gpl_selected.xml`; продажні ціни зафіксовані у пулі до наступного окремого перегляду GPL.

Назви, групи та ID чинних 950 карток зафіксовані з фінального експорту Prom від 12.08.2026.

## Захист

Нова версія не публікується, якщо:
- у пулі більше 1000 SKU;
- ACTIVE більше 1000;
- є дубль SKU або `offer id`;
- товар посилається на невідому групу;
- ціна постачальника некоректна;
- одночасно зникло більше 25 ACTIVE SKU з фідів постачальників.

Якщо окремий ACTIVE SKU тимчасово зник із фіда постачальника, попередня TALPA-картка зберігається у фіді, але примусово стає `available=false` і з кількістю `0`.
